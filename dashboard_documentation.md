# Interactive Sales Dashboard – Project Documentation

# 1. Introduction

This document explains the design, implementation, and insights of the Interactive Sales Dashboard created as part of Week 6 (Data Visualization Mastery with Seaborn). The dashboard combines statistical and interactive visualizations to help understand sales performance, pricing behavior, and relationships among key business metrics. The dashboard is implemented in a Jupyter Notebook (`dashboard.ipynb`) and uses Python libraries for data manipulation, visualization, and interactivity.

# 2. Project Objectives

The primary objectives of this project are:
* Visualize sales data in a clear and professional manner
* Understand data distribution and variability using statistical plots
* Identify relationships between numerical variables
* Provide interactive elements for deeper data exploration
* Present insights in a cohesive dashboard layout

# 3. Dataset Overview

The dashboard uses a sales dataset (`sales_data.csv`) containing transactional information. The key columns used in the analysis are:
| Column Name       | Description                      |
| ----------------- | -------------------------------- |
| Date              | Date of order
| Order_ID          | Unique identifier for each order |
| Product           | Name of the product sold         |
| Category          | Product category                 |
| Quantity          | Number of units sold             |
| Price             | Price per unit                   |
| Total_Sales       | Total sales value for the order  |
The dataset is clean and structured, making it suitable for visualization and statistical analysis.

# 4. Tools and Libraries Used

The following Python libraries were used in this project:
* Pandas – for data loading and manipulation
* Seaborn – for statistical visualizations (box plots, violin plots, heatmaps)
* Matplotlib – for figure layout, styling, and saving visual outputs
* Plotly – for interactive charts with hover information

# 5. Dashboard Structure

The dashboard is organized into multiple visual components, each focusing on a specific analytical question. All visualizations follow a consistent color theme and include titles and axis labels for clarity.

# 6. Visualization Descriptions and Interpretation

# 6.1 Box Plot – Price Distribution by Category
Purpose: The box plot shows how product prices are distributed within each category.
What it Shows: 
* Median price per category
* Price range and variability
* Presence of outliers
Interpretation: Electronics exhibit a wider price range compared to accessories, indicating higher variation in pricing.

# 6.2 Bar Chart – Total Sales by Product
Purpose: The bar chart compares total sales generated by each product.
What it Shows: 
* Relative sales performance of products
* Identification of top-performing products
Interpretation: High-value products such as laptops contribute the most to total revenue.

# 6.3 Heatmap – Correlation Analysis
Purpose: The heatmap visualizes correlations between numerical variables such as Quantity, Price, and Sales.
What it Shows: 
* Strength and direction of relationships between variables
Interpretation: Sales show a strong positive correlation with quantity, indicating that higher volume significantly increases revenue.

# 6.4 Violin Plot – Sales Distribution by Category
Purpose: The violin plot displays the distribution and density of sales values across categories.
What it Shows: 
* Distribution shape
* Concentration of sales values
Interpretation: 
Electronics show a broader sales distribution, suggesting varied order sizes.

# 6.5 Interactive Bar Chart – Product Sales (Plotly)
Purpose: This interactive chart allows users to explore sales data with hover details.
What it Shows: 
* Product-wise sales
* Additional information such as price and quantity on hover
Interpretation: 
Interactive elements make it easier to examine individual data points and identify patterns.

# 7. Dashboard Design Principles

* Consistent color palette across all charts
* Clear titles and labels for readability
* Logical layout for easy navigation
* Combination of static and interactive visuals

# 8. Key Insights

* Electronics generate the highest overall revenue
* Laptops are the top-selling product
* Sales are strongly influenced by quantity sold
* Accessories provide stable but lower revenue compared to electronics

# 9. Limitations

* The dataset is relatively small
* No time-based analysis is included
* Customer demographic data is not available
These limitations restrict deeper trend and customer behavior analysis.

# 10. Conclusion

The Interactive Sales Dashboard effectively demonstrates how statistical and interactive visualizations can be combined to analyze sales data. The dashboard provides clear insights into product performance, pricing behavior, and sales relationships.
